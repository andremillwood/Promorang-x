## Reference and capability boundaries
The mockups supply visual and journey direction, not production inventory. Review imagery and counts use controlled local fixtures. The live product displays actual records, actual imagery and explicitly unavailable artwork; it does not invent attendees, claims, verification or reward availability. A retained Piece alone does not assert verified attendance.

The reference-only crossover rewards, tier evolution criteria and cultural DNA percentages have no published API rules. This release exposes actual collection/provenance and identity facts instead of simulating those engines or inventing entitlements. Financial positions remain distinct from cultural memories.

## Intentional design overrides
Participant experience is intentionally dark, following all four supplied references. Orange actions use near-black ink; photographic containers use deliberate rounded corners and pill controls. Typography uses the existing DM Sans/space-glyph support. Critical credential framing and focus outlines are retained; decorative borders/gradients are reduced.
