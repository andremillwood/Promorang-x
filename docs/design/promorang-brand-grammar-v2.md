# PROMORANG Brand Grammar v2

Status: **Final discipline pass for Design Lab validation**

## Core idea

> **Movement that comes back with value.**

PROMORANG should not rely on repeated logos, orange borders, decorative boomerangs, or themed patterns to feel branded. The brand becomes recognizable because repeated product behaviors have repeated visual meaning.

The product thesis is:

> **The opportunity is the interface. Movement and return provide the brand grammar.**

## 1. The five proprietary meanings

Utility icons may remain familiar. Brand meaning may not.

### Move

Meaning: an opportunity enters the user's path or the user begins an action.

Visual behavior:
- outward directional stroke
- open trajectory
- clear origin and continuation

Do not use the Return mark for Move.

### Explore

Meaning: crossing into something new, nearby, adjacent, or worth discovering.

Visual behavior:
- dotted / intermittent path
- multiple waypoints
- spatial or relational feel

Best uses:
- Discover
- nearby context
- social movement
- route-like opportunity context

### Return

Meaning: value comes back after movement.

Visual behavior:
- hooked / curved return path
- obvious directional reversal
- open rather than closed

Best uses:
- recommendation provenance
- repeat behavior
- reward/value return
- post-action consequence

### Proof

Meaning: a verified event occurred.

Visual behavior:
- concentric stamp / target structure
- closed enough to feel resolved
- central mark indicating confirmation

Best uses:
- merchant validation
- receipt
- verified use
- credential confirmation

### Kept

Meaning: something useful or meaningful remains with the user.

Visual behavior:
- contained / closed shape
- nested center
- visually more stable than Move / Explore / Return

Best uses:
- Vault
- saved collectible
- retained access
- memory / relic

## 2. Mark discipline

PROMORANG should normally use **one major proprietary brand gesture per viewport**.

A second mark may appear only when it communicates a different product state or semantic consequence.

Bad:
- Return Arc in header
- Return Arc on image
- Return Arc in CTA
- Return Arc in explanation
- Return Arc as background watermark

Good:
- one Return mark beside a recommendation explanation because the opportunity returned to the user
- one Explore path on a world / nearby discovery surface
- one Proof stamp on a validated object

Recognition should come from consistency, not quantity.

## 3. P and brand anchor

The PROMORANG P represents identity / person / origin.

The P is appropriate for:
- product identity
- PromoCard issuer layer
- compact PromoKey object
- brand anchoring in Today

The P should not replace semantic marks. A P does not mean Return, Proof, or Kept.

## 4. World imagery truth rule

World surfaces must use imagery that is contextually true to the location or opportunity being presented.

If the interface says Kingston, imagery should depict Kingston / Jamaica or remain generic enough not to imply another city.

Do not pair city-specific copy with visibly contradictory landmarks.

Design Lab may use licensed placeholder media, but every placeholder must be replaceable by real merchant, creator, place, map, or editorial media in production.

## 5. Object materials

Object material follows object purpose.

### PromoCard — credential

Should feel:
- premium
- durable
- controlled
- legible
- status-aware

Use:
- dark credential surface
- subtle clay / gold light
- restrained linear texture
- issuer identity
- credential serial
- validity / uses / validation state

Avoid:
- decorative patterns that obscure information
- multiple competing brand marks

### Ticket — access

Should feel:
- tearable
- temporary
- event / reservation oriented

Use:
- warm sand / paper
- perforation or tear logic
- stub / access code

### Receipt — proof

Should feel:
- transactional
- verified
- returned after action

Use:
- thermal / lined paper
- mono data
- Proof mark
- issuer / benefit / place / verification

### Relic — kept meaning

Should feel:
- collectible
- darker / denser
- retained rather than transactional

Use:
- embossed or inset character
- violet / deep material where appropriate
- Kept mark
- provenance

### PromoKey — compact gated access

Should feel:
- small
- intentional
- functional
- unlock-oriented

Use:
- compact dark object
- P anchor
- Move or appropriate access mark

## 6. Motion grammar

Motion should make the product behave like the brand rather than adding animation for spectacle.

### Save / begin

`Move`

The opportunity leaves its current surface or gains directional intent.

### Discover / cross

`Explore`

The user moves through opportunities, places, people, or categories. Dotted path movement is appropriate.

### Use / redeem

The object moves outward toward validation.

### Merchant validates

`Return`

The motion reverses or resolves back toward the user with changed state.

### Receipt earned

`Proof`

The returned movement resolves into a stable confirmation mark.

### Vault retention

`Kept`

The result settles into a closed contained state.

Conceptual sequence:

```text
MOVE → EXPLORE → RETURN → PROOF → KEPT
```

Not every journey must show every state. The system should select only the states that are meaningful to the user's task.

## 7. Consumer screen application

### Today

Brand behavior:
- P may anchor identity/context
- one Return mark may explain why an opportunity came back to the user
- no decorative Return Arc repetition

Primary job:
- answer what is worth doing now

### Discover

Brand behavior:
- Explore owns nearby / crossing / discovery context
- individual rows may carry semantic marks when their state warrants it
- utility icons remain conventional

Primary job:
- surface real opportunities worth attention

### Card

Brand behavior:
- PromoCard remains a credential first
- Proof appears when validation is meaningful
- Return appears only when state actually returned value / consequence

### Vault

Brand behavior:
- Proof and Kept dominate
- object material should make access, receipt, relic, and value visibly different

### You

Brand behavior:
- marks can summarize movement history
- avoid turning identity into a badge wall

## 8. Data honesty

Design Lab may use illustrative:
- ratings
- distance
- availability
- verified uses
- social activity
- recommendation provenance

Production must only show these when backed by real data.

A missing signal should be omitted, never fabricated for visual completeness.

## 9. Cultural guardrail

PROMORANG may draw from broad principles such as:
- earth
- path
- terrain
- movement
- return
- rhythm
- repeated marks
- material / tactile contrast

PROMORANG must not copy or imitate identifiable Aboriginal, Torres Strait Islander, or other Indigenous sacred symbols, motifs, artworks, or culturally specific visual systems.

The five proprietary marks should evolve as original PROMORANG forms.

## 10. Production migration gate

Before any Brand Grammar element enters production, ask:

1. Does this mark communicate an actual product meaning?
2. Is it the correct semantic mark?
3. Is another proprietary mark already dominant in this viewport?
4. Is the underlying data real?
5. Is imagery contextually true?
6. Is the object material supporting the object's job?
7. Would removing the logo still leave the interaction recognizably PROMORANG?
8. Does the brand treatment preserve accessibility and information clarity?

## Locked principle

> **Utility familiar. Brand meaning proprietary.**

PROMORANG should feel branded because the user learns what Move, Explore, Return, Proof, and Kept mean through repeated product behavior—not because every surface is covered in brand decoration.
