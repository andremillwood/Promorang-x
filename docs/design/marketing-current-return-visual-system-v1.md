# Marketing Current + Return Visual System V1

Status: marketing-expression contract.  
Authority: `DESIGN.md` and `docs/design/promocard-world-experience-v1.md` remain product law.

## Purpose

The marketing suite may borrow composition density, editorial photography and cultural confidence from external references, but PROMORANG's own visual identity comes from its canonical world physics:

`NOTICE → CHOOSE → MOVE → PROVE → CONSEQUENCE → KEEP → RETURN`

and:

`THROW → FLIGHT → IMPACT → RETURN`

The boomerang is not decorative lore. It is the shape of movement and consequence.

## Visual primitives

### The Current
A fine trajectory moving through imagery, rails, Signals, Moments and objects. It may appear as:
- a curved line,
- a travelling dash,
- a subtle glow,
- a trail behind a rail,
- a section connector.

It must never imply fabricated live activity.

### The Return Arc
A curved path that visually brings consequence back toward PromoCard, receipt, retained proof or the next opening.

Do not use a literal boomerang icon as wallpaper. Prefer trajectory and return.

### Signal
A local interruption in the Current: one thing worth noticing now. Motion is allowed only to reinforce real state.

### Consequence
A receipt/object showing what counted, what changed and what came back. Illustrative marketing anatomy must be labelled as illustrative; production consequence objects require source truth.

### PromoCard
The primary persistent object. Marketing should sell its outcomes:
- watch what matters,
- see what actually opened,
- use real access/perks,
- prove supported actions,
- keep retained history,
- return when something materially changes.

PromoCard is where the Return lands; the plastic card face is not the entire proposition.

## Participant language

Do not force world-system terminology into action labels.

Use:
- Explore
- I'm interested
- Keep this
- Looking for something?
- Tell PROMORANG
- See what's out there
- Join
- Use perk
- Check in
- See what changed

Reserve terms such as Demand, market signal, supply and response for explanatory/operator contexts.

`Throw` is never a mandatory participant CTA.

## Motion

Motion must be purposeful:
- curved trajectory reveals,
- moving dash/current,
- signal pulse only when warranted,
- object entry along an arc,
- consequence returning toward PromoCard.

Avoid:
- constant decorative bouncing,
- fake live counters,
- casino motion,
- game HUD motion,
- motion that implies state not supported by data.

`prefers-reduced-motion: reduce` must preserve the visual path and hierarchy while removing continuous animation.

## Marketing composition law

External visual reference:
`photography + density + editorial hierarchy + cultural confidence`

PROMORANG signature:
`Current + Arc + Trail + Signal + Object + Receipt + Return`

Combined result:
cinematic cultural media moving through tangible PROMORANG objects, where useful action visibly travels outward and meaningful consequence visibly returns.

## Truth boundaries

- atmosphere ≠ Discovery
- editorial lens ≠ live inventory
- view ≠ interest
- interest ≠ Demand
- Demand ≠ supply
- threshold ≠ response
- response ≠ outcome
- Offer ≠ issuance
- claim ≠ redemption
- RSVP ≠ attendance
- proof submission ≠ verification
- marketing receipt anatomy ≠ production receipt
- Return visual ≠ guaranteed reward
