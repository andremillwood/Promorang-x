# PROMORANG Participant Convergence v1

Status: review / parallel convergence. Canonical production routes remain unchanged.

## Purpose

Prove that the locked PROMORANG brand grammar can carry a complete participant product before replacing `/home`, `/discover`, `/card`, `/vault`, or profile routes.

The review entry is `participant-next.html`. No-login review mode is the default. `?live=1` preserves the authenticated data path for later state QA.

## Five participant jobs

### Today — What should I do now?
One primary move owns the screen. Context, value, trust, time and action come before explanation. PromoCard continuity appears as an access shelf rather than repeating the hero benefit.

### Discover — What else is worth moving toward?
Discovery mixes one lead opportunity, compact nearby tracks, social context and a spatial Kingston layer. The core tabs are **For you / Nearby / Map / Saved**. Geography is supporting context, not the whole product.

### Card — What access do I have?
PromoCard is the durable credential. The surface must show the primary live credential, redemption state, additional access objects and recent returned proof. It must never collapse into one coupon plus empty space.

### Vault — What came back and remains mine?
Vault keeps its user-facing categories **Access / Proof / Kept / Value**. These are information architecture, not aliases for the five brand marks. Semantic marks describe behavior inside the categories. A recent archive gives time depth.

### You — Who am I becoming through participation?
You combines identity, belonging, quiet participation proof and a chronological trail of Return / Proof / Kept events. It is not primarily a settings screen or vanity-stat profile.

## Responsive contract

### Mobile
- single focused column
- one dominant action at a time
- bottom five-destination navigation
- no dashboard-style sidebars

### Desktop
- primary participant column plus a **context / world rail**
- context rail changes with destination
- rail may show spatial context, expiring access, nearby openings, card inventory, latest Vault additions, trail or scenes
- desktop must use the available canvas without turning PROMORANG into a dense admin dashboard

## Brand contract

Visual grammar stays locked:
- P = identity / person
- Move = outward opportunity
- Explore = dotted path / crossing
- Return = value comes back
- Proof = verified event
- Kept = contained retained value

Utility icons remain conventional. Brand semantics remain proprietary.

## Honesty contract

Review-mode numbers, ratings, distance, inventory and social context are illustrative and are visibly labeled as such.

Live mode must never fabricate:
- ratings
- distance
- availability
- verification
- inventory
- social proof
- personalization reasons

Real data or omission only.

## Migration gate

Do not switch canonical routes until:
1. review-mode responsive/product-depth QA passes;
2. live-mode empty/loading/error/real-data states are inspected;
3. existing role-aware contributor/merchant/host/operator behavior is preserved;
4. PromoCard redemption mechanics remain canonical.

Proposed production switch order remains:

**Today → Card → Vault → Discover → You**
