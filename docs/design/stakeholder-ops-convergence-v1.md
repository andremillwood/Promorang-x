# PROMORANG Stakeholder Ops Convergence v1

This branch contains the first controlled production convergence slice for stakeholder operations.

Scope is limited to Merchant validation and Host live-arrival/proof review. Existing production routes remain unchanged on main until this branch is reviewed.

Merchant validation must distinguish presented code, validated redemption and paid transaction evidence. Host operations must distinguish RSVP intent, verified arrival, walk-in and unresolved exception. Host proof review must distinguish submitted evidence, approved participation and downstream reward release.
