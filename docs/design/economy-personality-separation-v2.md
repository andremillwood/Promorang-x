# PROMORANG Economy Personality Separation v2

## Thesis

PROMORANG is one world with multiple product species.

The parent brand supplies the common grammar: P identity, movement / return logic, earth-signal palette, serif editorial confidence, proprietary semantic marks, and object / proof / kept semantics.

Subsystems must not collapse back into one repeated dark-card UI. A participant should be able to infer what kind of object or system they are looking at before reading the label.

## Shared rule

Utility can stay familiar. Product meaning must be proprietary.

Each subsystem requires its own:
- noun / object metaphor
- emotional job
- material / silhouette
- motion / interaction ritual
- trust job
- economic job
- lifecycle states
- return surface into Today / Discover / Card / Vault / You

## Discovery / Polls

### Noun
Signal field / city question.

### Emotional job
Influence, curiosity, visible momentum.

### Material
Open, kinetic, partially unresolved. Demand lanes, pulse fields, dotted trajectories, neighborhood / Scene distribution.

### Motion
Signals accumulate; lanes strengthen; patterns tip; a supply response can activate.

### Trust
Demand is never presented as confirmed supply. Totals, geography, time scope, and response state matter.

### Return
Discover → Today when urgent / activated → Moment when real supply exists → You as participation history.

## Pieces

### Noun
Archival kept artifact.

### Emotional job
Pride, memory, identity.

### Material
Tactile archive object: edition marks, provenance spine, acquisition origin, seal, series identity.

### Motion
Earn → keep → inspect → list → transfer while origin and proof remain attached.

### Trust
Earned and bought must remain distinguishable. Provenance outranks speculative price.

### Return
Vault collection / You identity / Discover and Marketplace when circulating.

## Piece Marketplace

### Noun
Gallery + verified exchange desk.

### Emotional job
Discernment, selectivity, trust.

### Material
Browse can feel collectible and visual. Settlement becomes sober and explicit: provenance, holder, utility, ask, fee, balance, transfer consequence.

### Motion
Inspect → verify → acquire / list → settle → update ownership / provenance.

### Trust
Provenance before price. Never imply guaranteed appreciation or investment return.

### Return
Discover entry / Vault collection management / You collection identity.

## PromoKeys

### Noun
Compact gated-access instrument.

### Emotional job
Privilege, readiness, exclusivity without opacity.

### Material
Notched / keyed silhouette, compact dimensions, lock / unlock cues. Distinct from PromoCard.

### Motion
Locked → unlocked → active → expiring → validated → returned as Proof.

### Trust
Issuer, venue, validity, unlock requirement, redemption requirement visible before use.

### Return
Today when newly unlocked / expiring → Card while active → Vault / You after use as Proof.

## PromoShare / Tickets

### Noun
Named draw campaign + serialized entries.

### Emotional job
Suspense, ceremony, anticipation.

### Material
Marquee / campaign vessel plus physical-feeling draw tickets with draw identity and serial / provenance.

### Motion
Open → countdown → ticket set lock → drawing → result reveal → claim / archive.

### Trust
Every entry belongs to one named draw. Ticket provenance, close time, prize, result and claim remain auditable.

### Return
Today when closing / result relevant → Vault for tickets and history → You for draw participation.

## Save & Win

### Noun
Protected principal vault + committed prize chamber.

### Emotional job
Safety plus possibility.

### Material
Protected / secure / ledger-like. Principal and prize must use visibly separate chambers.

### Motion
Choose → review → park → receive named-draw tickets → draw → principal remains / returns → result archived.

### Trust
Parking cannot resemble spending or loss. Prize funding / committed pool must remain separate from participant principal.

### Return
Vault as primary home → Today for closing / result signals → You for history.

## Gems

### Noun
Spendable internal value.

### Emotional job
Capability.

### Material
Faceted cyan value object + monetary-style source / destination ledger.

### Motion
Receive / spend / park / return / transact.

### Trust
Every change has a source and destination.

## Points

### Noun
Participation trace.

### Emotional job
Progress.

### Material
Accumulating path / milestone field rather than cash balance.

### Motion
Earn through participation, build standing / progression, unlock eligibility where applicable.

### Trust
Always explain why points were earned. Avoid money-like visual treatment.

## Tickets

### Noun
Named-draw entry.

### Emotional job
Chance.

### Material
Perforated / serialized draw object grouped by draw, not a universal currency tile.

### Motion
Earn → attach to draw → lock → result → archive.

### Trust
Named draw, source, state and result remain visible.

## Production gate

Do not promote v2 patterns into Participant Next or canonical routes until:
- object personality is approved visually
- mobile and desktop states are reviewed
- lifecycle states are complete
- trust / economic semantics are reconciled with current production behavior
- empty, loading, error, expired, unavailable and irreversible-action states are designed
- real data requirements are mapped
- no existing functionality is silently dropped
