# Merchant Outcome Taxonomy v1

Canonical standard merchant goals:

- `acquire_customers` — Get more customers
- `retain_customers` — Bring customers back
- `promote_item` — Promote something
- `fill_slow_period` — Fill a slow period
- `increase_bookings` — Get more bookings
- `increase_spend` — Increase spending
- `generate_reviews_content` — Get reviews or customer content
- `reward_customers` — Reward existing customers

These are presentation-layer intents. They should map to existing offer primitives rather than become a new persisted domain model unless later evidence requires it.
