# Stakeholder Next V5 — Worlded Workflows

## Thesis
Participant Next personality + Stakeholder Next operational maturity.

V5 moves beyond visual branding. The work itself should visibly transform through PROMORANG's semantic lifecycle while retaining truthful operational states.

## Shared lifecycle
- **Move** — issue, publish, operate, launch
- **Explore** — possibility, demand, audience/market signal
- **Proof** — evidence crosses a verification boundary
- **Return** — value, customer, decision, or correction comes back
- **Kept** — provenance, ownership, history, and residue remain

These marks are functional product semantics, not decoration.

## World context
Desktop review gains a Participant-Next-like context rail containing the real-world subject of the work: asset, place, Moment, offer, evidence pack, client folio, or source record. Lifestyle/media imagery is used only where the stakeholder job naturally concerns people/places/assets; Admin remains forensic and source-record oriented.

Mobile and narrower desktop layouts preserve the operational shell without forcing the context rail below the work.

## Role expression

### Creator
Studio field kit. Current creative asset, place context, proof edge, version history, review residue, and proof-gated submission. A completed commission should be able to become a Kept portfolio/provenance object.

### Host
Backstage field operations. Moment/venue context, pass object, run strip, arrival trail, explicit exceptions, and proof close. RSVP remains demand intent until arrival is written.

### Merchant / Venue
Counter instruments. Offer behaves like a Key; validation behaves like a terminal write; confirmed use leaves a receipt; purchase and fulfillment remain separate; repeated use contributes to retained place history.

### Brand
Activation fieldbook. Market activity, people/places, evidence-source fragments, proof strength, and decision residue. Stop/Change/Scale must cite evidence rather than projected ROI.

### Agency
Client operating folio. Client-owned truth, agency-operated work, managed result pack, visible ownership boundary, and next brief generated from evidence.

### Admin
Evidence archive. Source record, dispute, evidence chain, correction, and archive. No lifestyle imagery. Original state remains inspectable after append-only correction.

## Design gate
A stakeholder destination is not mature because it looks branded. It is mature when:
1. the work object is recognizable;
2. its lifecycle state is visible;
3. evidence and consequences are legible;
4. PROMORANG semantics map to actual transitions;
5. role personality changes the object/material system, not merely the accent color;
6. real-world context appears where it materially helps operate the work;
7. retained history/provenance is visible after completion.

## Migration rule
The V5 review remains illustrative. Approved world/object treatments should migrate into the already-live-converged Host, Merchant, Creator, Brand, Agency, and Admin components without replacing their real data, hooks, mutations, or truth boundaries.
