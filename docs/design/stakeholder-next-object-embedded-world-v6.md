# Stakeholder Next V6 — Object-Embedded World

## Thesis

**The object is the world.**

V5 proved that context rails can reconnect stakeholder work to people, places, media and evidence. V6 moves the strongest context into the primary work objects themselves so PROMORANG personality is not dependent on a sidebar.

## What stays locked

- stakeholder job clarity
- five-destination operating model
- truth distinctions between intent, proof, transaction, fulfillment, approval and settlement
- existing live-converged capabilities beneath the review shell
- restrained use of expressive serif typography

## Shared PROMORANG lifecycle

- **Move** — issue, publish, launch, operate
- **Explore** — possibility, demand, market signal
- **Proof** — cross an evidence boundary
- **Return** — value, customer, decision or correction comes back
- **Kept** — provenance and retained history remain

These semantics belong on objects and state transitions, not as decorative iconography.

## Role-native language

### Creator
Today · Briefs · Studio · Proof · Value

The brief carries place, current asset, revision residue and proof requirements. Studio carries contact-sheet/media identity and the current proof edge.

### Host
Tonight · Moments · Door · Proof · Return

The run sheet carries Moment identity. Door carries the RSVP → Door → Verified → Proof path. Exceptions explicitly preserve the fact that no attendance was written.

### Merchant / Venue
Now · Offers · Validate · Orders · Places

The offer is treated as a Key-like commercial instrument. Validation becomes a proof-writing device. Confirmed use leaves a receipt while purchase and fulfillment remain distinct.

### Brand
Today · Activations · Network · Evidence · Decisions

The Activation Dossier and Evidence Pack carry field activity and source composition inside the object. Creator, Host and Merchant evidence remains source-distinct.

### Agency
Today · Clients · Work · Proof · Growth

The client folio carries visible ownership boundaries: the client owns decisions and underlying truth; the agency operates the work and packages managed results.

### Admin
Today · Cases · Review · Economy · Health

Admin is an evidence archive. Review surfaces become case files rather than generic dark cards. Source → Review → Decision → Archive remains visible and corrections append rather than erase history.

## Rail rule

The V5 context rail is now secondary. On large desktop it is visually reduced to one contextual card. Lifecycle residue moves into the main work objects. On smaller screens, core work retains priority.

## Media rule

Media appears only where the underlying work genuinely has a person/place/product/creative subject. Admin uses forensic source records rather than lifestyle imagery.

## Convergence rule

V6 remains an illustrative design benchmark. Approved object language should be carried into the already-converged live components rather than replacing live capability with mock data.

## Quality gate

A V6 destination passes only when:

1. the primary object is recognizable without the context rail;
2. the object carries its place/media/source context where relevant;
3. lifecycle state is visible through the object itself;
4. role personality is distinct without breaking PROMORANG coherence;
5. operational truth remains more important than branding;
6. removing the rail would not remove the meaning of the screen.
