# Momentum Engine Roadmap

## Phase 1: Operational Core

Objective: make the platform credible.

Deliver:
- moment types: digital, physical, hybrid
- gathering thresholds and pulse states
- memory issuance
- rarity tiers
- perk model
- venue capacity governors
- multi-modal proof
- creator content moments
- digital-to-physical attribution path

Exit criteria:
- real moments can trigger gatherings safely
- completions can issue memories
- hybrid actions can be tracked end-to-end

## Phase 2: Retention Core

Objective: stop being a one-time reward app.

Deliver:
- pulse vault
- memory collections
- active perk management
- participant legacy rank
- catalyst and impact dashboard
- venue return and redemption reporting

Exit criteria:
- memory holders return more than cash-only users
- legacy rank and perk loops are visible and used

## Phase 3: Network Effects

Objective: reward users who create momentum, not just consume it.

Deliver:
- first mover incentives
- catalyst attribution
- viral share logic
- creator-to-venue conversion reporting
- sponsored vaults and memory sets

Exit criteria:
- measurable downstream action from catalysts
- creator and venue loops reinforce each other

## Phase 4: Agent Readiness

Objective: expose the platform to the global agentic economy.

Deliver:
- discovery APIs
- optimization APIs
- execution-prep APIs
- proof APIs
- legacy portfolio APIs
- scoped authorization for agent actions

Exit criteria:
- agents can query opportunities and prepare users safely
- Promorang value is machine-readable

## Phase 5: Advanced Surfaces

Objective: expand cultural and economic depth without breaking trust.

Potential deliverables:
- social gifting of eligible memories
- creator-to-venue direct marketplace
- collection vault campaigns
- AR threshold visualization
- advanced partner tooling

These should only proceed after trust, safety, and proof systems are stable.
